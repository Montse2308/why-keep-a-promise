This page is static: plain files built with Astro, a tool that turns code into web pages, and
TypeScript, a language that catches mistakes before the page is built. Your browser only runs the
table's code, in its three moments; the rest is text and drawing. The table is drawn in SVG, a
format for describing shapes in code, and the scene at the top moves with the scroll through CSS
alone, the language that styles the page.

Every figure is computed with exact arithmetic, as fractions of whole numbers, so nothing is
rounded until it is shown. The payoffs come from the published instructions of Vanberg (2008); the
rates and guesses were recalculated from his public supplementary data, with the method of his own
code. Tests, small programs that check the code, fail if any figure changes.
