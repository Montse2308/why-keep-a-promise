# Archivo

Lo que ya no rige. Se conserva como registro de cómo se llegó a las decisiones vigentes; no se sigue
ni se cita como regla. Lo vigente está en `docs/plan.md`, `docs/content-rules.md`, `docs/phases.md`,
`docs/tasks.md` y `docs/decisions/` (ADR 0021).

| Archivo | Qué fue |
| ------- | ------- |
| `decisiones/` | Los ADR que dejaron de regir, cada uno con la línea de qué lo reemplaza. |
| `plan-anterior.md` | El plan de los seis actos (F0–F4, con el rediseño R0–R4). |
| `reglas-anteriores.md` | Las reglas de contenido antes de la película. |
| `fases-anteriores.md` | Las fases F0–F4 y R0–R4, con sus criterios de salida. |
| `tareas-anteriores.md` | Las listas de tareas de esas fases, con lo que quedó pendiente. |

Este archivo se versiona y entra en la auditoría del historial del paso 3 del checklist (ADR 0012).
