# Decisiones vigentes

`docs/archivo/decisiones/` con una línea que dice qué lo reemplaza. Lo que sigue valiendo de él se
escribe otra vez en el ADR nuevo (ADR 0021). Una decisión cambia solo con un ADR nuevo, y los
números no se reutilizan.
